# Lab 4 : Styliser un composant avec StyleSheet – Application BookShelf
## Objectif

L'objectif de ce TP est d'améliorer l'apparence de l'application BookShelf et d'organiser les styles à l'aide de l'API StyleSheet de React Native.

## Réalisation

Dans un premier temps, nous avons modifié les couleurs, les tailles des textes et les espacements des composants BookShelfHeader, WelcomeScreen et BookShelfFooter pour obtenir une interface plus moderne et cohérente.

Ensuite, nous avons remplacé les styles en ligne par des styles définis dans StyleSheet.create(), afin de rendre le code plus propre, lisible et facile à maintenir.

## Résultat final

L'application BookShelf possède désormais une interface harmonieuse avec les nouvelles couleurs et des styles bien organisés.
